## Prerequisites

### 1. Docker Desktop (required — not yet installed)

Download and install Docker Desktop for Windows:
https://www.docker.com/products/docker-desktop/

After install, confirm it works:
```powershell
docker --version
docker compose version
```

### 2. Clone Auto Browser

```powershell
cd "C:\Users\eliwa\Documents\Claude\Projects\My Context\job-pipeline"
git clone https://github.com/LvcidPsyche/auto-browser.git auto-browser
```

### 3. Configure Auto Browser

```powershell
cd auto-browser
Copy-Item .env.example .env
```

Edit `.env` — set at minimum:
```
API_BEARER_TOKEN=<generate a random 32-char string>
AUTH_STATE_ENCRYPTION_KEY=<generate a 44-char Fernet key>
```

Generate keys:
```python
import secrets, base64, os
print("BEARER:", secrets.token_urlsafe(32))
print("FERNET:", base64.urlsafe_b64encode(os.urandom(32)).decode())
```

Set in pipeline env or `pipeline_config.env`:
```
AUTO_BROWSER_TOKEN=<your BEARER value>
AUTO_BROWSER_URL=http://127.0.0.1:8000
```

### 4. Start Auto Browser

```powershell
cd "C:\Users\eliwa\Documents\Claude\Projects\My Context\job-pipeline\auto-browser"
docker compose up --build
```

Verify it's running:
- API dashboard: http://127.0.0.1:8000
- noVNC (visual browser): http://127.0.0.1:6080

## Daily Usage

### Apply to All Processing Jobs

```powershell
python scripts\apply.py --all
```

This:
- Picks up all `handoff_queue/processing/*.json` files that have a cover letter
- Detects the platform from the job URL
- Applies up to the daily cap for each platform
- Auto-approves LinkedIn Easy Apply; pauses all others for your review

### Apply to One Specific Job

```powershell
python scripts\apply.py --job handoff_queue/processing/u-s-climate-alliance-secretariat_research-intern.json
```

### Check Status + Daily Caps

```powershell
python scripts\apply.py --status
```

### Approve a Paused Application

When `apply.py` pauses for approval, it prints:
```
APPROVAL REQUIRED for Acme Corp
Review at: http://127.0.0.1:8000/sessions/<id>
noVNC:     http://127.0.0.1:6080
To approve: POST http://127.0.0.1:8000/approvals/<approval_id>/approve
```

Open the noVNC link, review the filled-out form, then POST the approve endpoint to submit.

## Failure Handling

| Situation | What happens |
|-----------|-------------|
| CAPTCHA | Agent requests human takeover → open noVNC to solve |
| Auth expired | Re-run `--save-linkedin-auth` to refresh the profile |
| Form field unrecognized | Agent logs observation and stops; manual fallback |
| Site blocks automation | Logged to apply_log.json; fall back to manual application |
| Auto Browser not running | `apply.py` prints instructions to start it |
